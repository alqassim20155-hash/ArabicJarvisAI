# Arabic Jarvis AI v7 — Phone Dashboard (patch)

هذا تحديث تدريجي مبني على ملفات v6، لا يستبدل مشروع Android الكامل.

## التغييرات
- إعادة تصميم ودجت 4×4 مع عنوان، حالة، أزرار محادثة وصوت، تشغيل وإيقاف، وزر فحص مستقل.
- إضافة اختصارات Wi-Fi، المتصفح، الخرائط، واتساب ويوتيوب إلى جانب الكاميرا والهاتف والإعدادات.
- إضافة أوامر نصية وصوتية: «افتح الواي فاي»، «افتح الخرائط».
- الحفاظ على تكامل Bridge القائم دون تعديل رموز المصادقة أو الخادم.

## التثبيت
1. احفظ نسخة احتياطية من مجلد app.
2. فك الضغط داخل جذر ~/ArabicJarvisAI.
3. شغّل git diff --check وراجع git diff قبل الرفع.
4. شغّل بناء GitHub Actions، ثم اختبر الأزرار على الهاتف.

## قيود مهمة
- الودجت يفتح Activity لتنفيذ الاختصارات، ولا ينفذ أوامر النظام في الخلفية بشكل مستقل.
- حالة السيرفر تتحدث عند تفاعل التطبيق ولا تعد مراقبة فورية مستمرة.
- بعض التطبيقات قد لا تكون ظاهرة بسبب قيود package visibility أو عدم التثبيت.
- لا يوجد استماع دائم أو خدمة Accessibility أو تحكم غير مقيد بالتطبيقات في هذه النسخة.
- لم يتم إجراء بناء Gradle أو اختبار فعلي على Android 17.
