# Jarvis v6 — Widget + Phone Commands (patch)

هذا تحديث تدريجي على v5، ولا يغير Bridge أو رمز المصادقة.

## الجديد
- ودجت 4×4 أكثر كثافة: تحدث، محادثة، تشغيل، إيقاف، كاميرا، هاتف، إعدادات، وفحص حالة بالضغط على سطر الحالة.
- أوامر صوتية/نصية: افتح الكاميرا، افتح الهاتف، افتح المتصفح، افتح واتساب، افتح يوتيوب، افتح تيليجرام (والمرادفات الإنجليزية).
- يفتح تطبيقات الهاتف عبر Android intents، ولا يستخدم Accessibility أو صلاحيات جذر.

## التثبيت
1. انسخ نسخة احتياطية من المشروع الحالي.
2. فك الضغط داخل ~/ArabicJarvisAI مع الحفاظ على المسارات.
3. أضف إلى AndroidManifest.xml داخل <queries> إن كانت غير موجودة:
<package android:name="com.whatsapp" />
<package android:name="com.google.android.youtube" />
<package android:name="org.telegram.messenger" />
4. git diff --check ثم ابنِ APK من GitHub Actions.
5. احذف الودجت القديم وأضف الجديد بحجم 4×4.

## حدود النسخة
- زر الودجت يفتح MainActivity ثم ينفذ الإجراء؛ لا يعمل بصمت في الخلفية.
- التطبيقات التي لم تُثبت أو لا تتاح للاستعلام قد لا تُفتح.
- لم يتم بناء APK أو اختبار التشغيل على هاتف حقيقي هنا.
- الودجت ليس حيًّا في الخلفية: تحديث الحالة يتبع التطبيق.
- لا توجد صلاحيات شاملة لتغيير إعدادات النظام المحمية.
